# Lara Corsini | Segurança dos Alimentos - site institucional

Site one-page de **Lara Corsini**, médica veterinária com atuação em segurança dos alimentos: assessoria, consultoria, responsabilidade técnica, treinamentos e documentação em Balneário Camboriú e região.

## Estrutura

```
index.html   # página única (hero, sobre, para quem, serviços, como funciona, localização, FAQ)
styles.css   # estilos (verde-petróleo da marca LC, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # foto da Lara, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Conteúdo

Textos de capa, sobre, serviços, "Como funciona o meu trabalho?", localização, atendimento, FAQ, CTA final e rodapé enviados pela Lara em 08/10/2026.
