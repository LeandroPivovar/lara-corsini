# Lara Corsini | Segurança de Alimentos - site institucional

Site one-page de **Lara Corsini**, médica veterinária com consultoria em segurança de alimentos em Balneário Camboriú - SC.

## Estrutura

```
index.html   # página única (hero, sobre, para quem, serviços, treinamento, depoimentos, mapa, FAQ)
styles.css   # estilos (verde-petróleo da marca LC, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # foto da Lara, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Depoimentos** são exemplos. Substitua por avaliações reais de clientes.
- **Foto da Lara** (`assets/lara.png`) foi recortada do print do WhatsApp, em baixa resolução. Troque por uma foto original.
- **Logo:** o logo "LC" do banner estava coberto pela foto no print, então o site usa um monograma "LC" em texto. Envie o arquivo do logo para substituir.
- **Serviços:** a lista (Manual de Boas Práticas, POPs, RT, treinamento, rotulagem, produtos de origem animal) é a base comum da área. Confirme o que a Lara oferece e, se quiser, inclua o número do CRMV.
- **Horário:** o perfil mostra quinta-feira, 08h às 18h. O site diz "08h às 18h, com visita agendada". Ajuste se os outros dias forem diferentes.
- Contato: WhatsApp `+55 47 9125-1221` (`wa.me/554791251221`) e `lcsegurancadealimentos@gmail.com`.
